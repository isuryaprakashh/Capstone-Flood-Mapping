Title & Institutional Objectives (O1 – O5)

Build a deep learning pipeline to extract building footprints and road networks from pre/post satellite imagery, spot flood damage, and render actionable maps for rescue teams.

O1 Data Pipeline GeoTIFF tiling & CRS alignment
O2 Baseline Model PyTorch U-Net feature extractor
O3 Fusion Network Siamese Cross-Attention novel AI
O4 Web System FastAPI backend & Leaflet map
O5 MLOps & Tests pytest coverage & Docker container

Tech Stack & Environment Setup (.env)

PyTorch 2.x Deep Learning

Core framework for training U-Net baseline and Siamese Cross-Attention fusion segmentation models.

TorchGeo Spatial Datasets

PyTorch extension for spatial sampling, GeoTIFF loading, and geospatial data augmentation.

Rasterio 1.3+ GeoTIFF I/O

Geospatial raster I/O for reading multi-band satellite imagery, CRS reprojecting, and metadata parsing.

GDAL 3.x GIS Abstraction

Underlying geospatial library for high-performance raster/vector conversions and coordinate systems.

FastAPI Backend API

Asynchronous Python backend microservice serving real-time inference and routing endpoints.

React / Leaflet Map Frontend

Interactive web frontend map dashboard for visualizing pre/post tiles and flood damage overlays.

MongoDB Database

NoSQL database for storing model prediction metadata, session logs, and disaster zone polygons.

NetworkX 3.x Graph Engine

Graph theory engine for building road network topology and routing rescue vehicles around flooded roads.

Docker Containerization

NVIDIA GPU-enabled container setup for reproducible training environments and cloud deployment.

pytest Testing & MLOps

Automated unit and integration test suite covering API routes, loss functions, and data transformations.
